# Reading Stack (docs/paper)

Danh mục bài báo nghiên cứu cho mô hình Decoder-only Transformer và emotional support response generation.

## S0: Architecture & Core Task

1. **Attention Is All You Need** (Vaswani et al., 2017)
   - File: `1706.03762v7.pdf`
   - Link: [arXiv:1706.03762](https://arxiv.org/abs/1706.03762)
   - Scope: Scaled dot-product attention, multi-head attention, residual connections, layer normalization, FFN.

2. **MiniGPT: Rebuilding GPT from First Principles** (2026)
   - File: `2605.17398_MiniGPT_Rebuilding_GPT_from_First_Principles.pdf`
   - Link: [arXiv:2605.17398](https://arxiv.org/abs/2605.17398)
   - Scope: Decoder-only autoregressive LM từ đầu (embedding, causal attention, cross-entropy, autoregressive generation).

3. **Towards Emotional Support Dialog Systems** (Liu et al., 2021)
   - File: `2106.01144_Towards_Emotional_Support_Dialog_Systems.pdf`
   - Link: [arXiv:2106.01144](https://arxiv.org/abs/2106.01144)
   - Scope: Định nghĩa bài toán Emotional Support Conversation (ESC), ESConv dataset, support strategies taxonomy.

## S1: Behavior & Multi-Strategy

4. **Towards Empathetic Open-domain Conversation Models** (Rashkin et al., 2019)
   - File: `1811.00207_Towards_Empathetic_Open-domain_Conversation_Models_a_New_Ben.pdf`
   - Link: [arXiv:1811.00207](https://arxiv.org/abs/1811.00207)
   - Scope: EmpatheticDialogues dataset, grounding hội thoại vào bối cảnh cảm xúc.

5. **Schema-Guided Response Generation using Multi-Frame Dialogue State** (2025)
   - File: `2508.20635_Schema-Guided_Response_Generation_using_Multi-Frame_Dialogue.pdf`
   - Link: [arXiv:2508.20635](https://arxiv.org/abs/2508.20635)
   - Scope: Điều khiển response theo dialogue state và strategy Motivational Interviewing.

6. **Modeling Multiple Support Strategies within a Single Turn** (2026)
   - File: `2604.17972_Modeling_Multiple_Support_Strategies_within_a_Single_Turn_fo.pdf`
   - Link: [arXiv:2604.17972](https://arxiv.org/abs/2604.17972)
   - Scope: Kết hợp nhiều strategy trong một câu trả lời (reflection + reassurance + suggestion).
